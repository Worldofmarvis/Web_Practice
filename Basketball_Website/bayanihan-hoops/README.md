# Bayanihan Hoops League Website

A six-page website for a fictional community basketball league. It is built with HTML only (no CSS yet) and focuses on clean structure and accessibility.

## Pages

| Page | File |
| --- | --- |
| Home | `index.html` |
| Teams | `pages/teams.html` |
| Schedule and Standings | `pages/schedule-standings.html` |
| Register | `pages/register.html` |
| News (with audio and video) | `pages/news.html` |
| Contact and Venue | `pages/contact.html` |

## Folders

- `pages/` holds every page except the home page.
- `images/` holds the logo, favicon, team badges and the court picture (all SVG).
- `media/` holds the audio clip.
